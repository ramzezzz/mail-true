# Фирменный стиль Mail.True

Все ресурсы лежат в `brand/`, живой каталог — `brand/preview.html`
(открывается локально, ничего не тянет из сети).

## Идея

Mail.True — «настоящая почта»: своя, на своём сервере, без чужих глаз и
рекламы. Стиль должен внушать спокойное доверие — этим продуктом организация
пользуется каждый день, поэтому ничего кричащего; но и не безликость — у
продукта есть характер: инженерная честность.

## Знак

**Почтовая марка с галочкой-клапаном.**

- Квадрат с перфорацией по краям — почтовая марка. Марку печатает тот, кто
  сам отвечает за свою почту: свой сервер, свой штемпель. Перфорация — три
  полукруглые выемки на сторону — делает знак узнаваемым силуэтом, а не
  «просто квадратиком с галочкой».
- Внутри — галочка. Её левое плечо идёт под 45° — это линия клапана конверта
  (почта); правое плечо уходит выше горизонта — это «true» (подлинность,
  проверено). Один росчерк, два смысла.
- Никакого конвертика с птичкой и градиентов: одна заливка, один штрих.

Файлы:

| Файл | Что это |
| --- | --- |
| `brand/logo/logo-full.svg` | знак + написание, светлый фон (186×32) |
| `brand/logo/logo-full-dark.svg` | то же для тёмного фона |
| `brand/logo/mark.svg` | только знак, 32×32, светлый фон |
| `brand/logo/mark-dark.svg` | знак для тёмного фона |
| `brand/logo/mark-mono.svg` | одноцветный контурный, наследует `currentColor` |
| `brand/favicon/favicon.svg` | основной масштабируемый favicon |
| `brand/favicon/favicon-16.svg` | 16×16 — **своя геометрия**: без перфорации, штрих толще |
| `brand/favicon/favicon-32.svg`, `favicon-48.svg` | полный знак под конкретный размер |

В 16×16 перфорация превращается в шум, поэтому у мелкого фавикона плоский
скруглённый квадрат и утолщённая галочка — знак остаётся читаемым.

### Написание

MAIL.TRUE набрано не шрифтом, а нарисовано штрихами (моноширинный по духу
«инженерный» рисунок: открытые формы, круглые окончания штрихов) — написание
не зависит от установленных шрифтов и всегда выглядит одинаково.
«MAIL» — в цвете основного текста, точка-марка и «TRUE» — в фирменном синем:
акцент падает на «настоящую» часть имени. Точка между словами — миниатюра
знака (скруглённый квадрат), связывает написание со знаком.

### Правила применения

- **Охранное поле** — не меньше высоты знака со всех сторон (для знака 32px —
  по 32px пустоты вокруг).
- **Минимальные размеры**: полный логотип — 116px по ширине (высота знака
  20px); отдельно знак — 16px. Меньше — только упрощённый фавикон.
- На тёмном фоне использовать только `*-dark`-варианты: базовый синий #006EC6
  на тёмном фоне даёт контраст всего 3.43:1 — сам знак ещё различим, но
  осветлённый акцент #5CA8F5 держит 7.10:1.
- **Нельзя**: перекрашивать знак вне палитры, добавлять тени и градиенты,
  наклонять, ставить написание вертикально, отделять галочку от марки,
  менять пропорции знака и написания, ставить знак на пёструю фотографию.

## Палитра

### Решение по основному цвету

Интерфейс повторяет mail.ru, у которого фирменный синий #0077FF. Уходить в
другой оттенок (зелёный, фиолетовый) — значит сломать привычность, ради
которой всё затевалось: пользователь должен сесть и работать. Но копировать
#0077FF нельзя — и по вкусу (это чужой цвет), и по доступности: **#0077FF на
белом даёт контраст 4.13:1 — не проходит WCAG AA для обычного текста**.

Поэтому основной цвет — **True Blue #006EC6**: тот же привычный синий по
тону, но глубже и спокойнее. Он проходит AA (≥4.5:1) как цвет текста и ссылок
на всех трёх фонах интерфейса и одновременно работает фоном кнопки под белый
текст. Название цвета совпадает с именем продукта — это осознанно.

## Типографика

Требование: шрифты лежат в проекте и раздаются со своего сервера — почта
может стоять в закрытом контуре без интернета. Оба выбранных шрифта — под
свободной лицензией SIL OFL 1.1 (тексты лицензий рядом с файлами).

| Шрифт | Роль | Почему |
| --- | --- | --- |
| **Golos Text** (variable, 400–900) | весь интерфейс: списки, меню, кнопки, заголовки | рисован российской студией для текста госсервисов: безупречная кириллица (это главное — почта русскоязычная), нейтрально-деловой характер, близок по пропорциям к VK Sans, которым набран mail.ru, — привычная плотность строк сохраняется |
| **JetBrains Mono** (variable, 100–800) | технический текст: исходники писем, DKIM-ключи, DNS-записи в админке, журналы | различимость похожих символов (0/O, 1/l) критична, когда администратор сверяет ключ или адрес сервера; лицензия OFL |

Файлы (`brand/fonts/`): `golos-text-{latin,cyrillic}-wght.woff2`,
`jetbrains-mono-{latin,cyrillic}-wght.woff2` + `fonts.css` с `@font-face`
(unicode-range разрезает загрузку по алфавитам). Всё вместе — около 112 КБ,
переменные файлы закрывают все начертания одной загрузкой.

## Значки

`brand/icons/` — 23 значка + `sprite.svg`. Единые правила:

- сетка **24×24** (`viewBox="0 0 24 24"`), живая область 20×20 с полями по 2px;
- штрих **1.8**, `stroke-linecap="round"`, `stroke-linejoin="round"`;
- контурные, без заливок; единственное исключение — точки-акценты
  (метка, непрочитанное, важное) заливаются `currentColor`;
- цвет всегда наследуется через `currentColor` — значок перекрашивается
  палитрой, сам цветов не знает;
- в 16px значки уменьшаются без правок (штрих остаётся ощутимым),
  для крупных размеров масштабируются как есть.

Состав:

| Группа | Файлы |
| --- | --- |
| Папки | `folder-inbox`, `folder-sent`, `folder-drafts`, `folder-spam`, `folder-trash`, `folder-archive` |
| Действия | `compose`, `reply`, `reply-all`, `forward`, `delete`, `archive`, `move-to-folder`, `label`, `flag`, `attach`, `print`, `search`, `settings` |
| Состояния | `read`, `unread`, `important`, `send-error` |

Родство со знаком: `read` — конверт с той же галочкой, `unread` — конверт с
точкой цвета акцента, как точка непрочитанного в списке писем.

Спрайт: `<svg width="24" height="24"><use href="sprite.svg#icon-reply"/></svg>`;
идентификаторы — `icon-<имя-файла>`.

## Проверено

- Все 33 SVG разобраны XML-парсером — валидны.
- Все значки: один `viewBox`, один штрих 1.8, round-скругления (проверено скриптом).
- Спрайт содержит все 23 symbol с правильными id.
- Все ссылки из `preview.html` (шрифты, фавиконки, tokens.css) указывают на
  существующие файлы.
- Все числа контрастности в этом документе — результат расчёта по формуле
  WCAG 2.x, а не оценка на глаз.
