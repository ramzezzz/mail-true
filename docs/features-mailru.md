# Функциональность mail.ru: что снято с живого интерфейса

Каталог возможностей, которые нужно повторить. Снято 2026-08-05 с рабочего
ящика. Скриншоты — в `research/mailru/`.

## Карта настроек

Настройки живут по адресу `/settings/` и оформлены **иначе, чем сама почта**:
светлая тема, простая шапка портала, карточки на белом фоне, без фонового
изображения. Заголовки: `h1` 32px/36px вес 500, `h2` 28px/32px вес 500.

| Раздел                | Адрес                   | Что внутри                                                                                   |
| --------------------- | ----------------------- | -------------------------------------------------------------------------------------------- |
| Главная               | `/settings`             | Плитка карточек-ссылок на остальные разделы                                                  |
| Общие                 | `/settings/general`     | Имя и подпись, автоответчик, уведомления, отправка, поведение после удаления, адресная книга |
| Фильтры               | `/settings/filters`     | Правила фильтрации и пересылки                                                               |
| Папки                 | `/settings/folders`     | Дерево папок, создание, доступ по паролю                                                     |
| Почта с других ящиков | `/settings/collector`   | Сбор почты по IMAP и POP3                                                                    |
| Анонимайзер           | `/settings/aliases`     | Одноразовые адреса-псевдонимы                                                                |
| Управление рассылками | `/settings/cleanmaster` | Массовая отписка от рассылок                                                                 |
| Лог действий          | `/settings/actions`     | История входов и действий                                                                    |

Разделы «Красивый адрес», «Детская почта», «Бета-тестирование», «Реклама»,
«Данные из писем» — особенности сервиса mail.ru, нам не нужны.

## Общие настройки: перечень параметров

- **Имя отправителя и подпись** — имя, несколько подписей, выбор подписи по умолчанию
- **Автоответчик** — включение, текст, срок действия
- **Уведомления** — в браузере, во вкладке (счётчик в заголовке)
- **Отправка писем** — включать содержимое исходного письма в ответ
- **После удаления письма** — переходить к следующему письму или к списку
- **Адресная книга** — автоматическое пополнение контактов

## Правила фильтрации

Ровно то, что умеет Sieve — язык фильтрации Dovecot. Это удачно: наши правила
транслируются в Sieve один в один, без своей машины исполнения.

**Условия** (поле, оператор, значение; условий может быть несколько):

| Поле                      | Примечание         |
| ------------------------- | ------------------ |
| Поле «От»                 |                    |
| Поле «Кому»               |                    |
| Поле «Тема»               |                    |
| Поле «Копия»              |                    |
| Поле «Переадресовано от»  |                    |
| Поле «Переадресовано для» |                    |
| Поле «Размер, Кб»         | числовое сравнение |

Оператор по умолчанию — «содержит».

**Действия**:

- Поместить в папку (выбор папки)
- Пометить прочитанным
- Пометить флагом
- Применить к письмам, которые уже находятся в папках (выбор папок) —
  то есть правило прогоняется по уже полученной почте, не только по новой
- Переслать копию сообщения на адрес
- Отвечать автоматически
- После срабатывания этого фильтра применять другие фильтры (по умолчанию включено)
- Применять фильтр к спаму (по умолчанию выключено)

Правила упорядочены, порядок меняется стрелками. Каждое можно включить или
выключить переключателем, не удаляя. Отдельная кнопка «Добавить пересылку» —
упрощённый случай правила. Флажок «Показывать автофильтры» открывает правила,
которые сервис завёл сам.

## Сбор почты с других ящиков

Формулировка сервиса: «Настройте сбор писем с любого сервера, работающего по
протоколу IMAP или POP3». Быстрые кнопки популярных: Яндекс, Gmail, Yahoo,
Outlook, и «Другая почта» для ручной настройки.

Порядок: адрес ящика → пароль → настройки сервера (для известных подставляются
сами) → выбор папки-приёмника. Ровно эта схема нужна и нам, плюс наш вариант
с прямым подключением без перекладывания писем.

## Просмотр письма

Панель действий, слева направо (высота кнопок 36px):

| Действие   | Позиция по X | Ширина |
| ---------- | ------------ | ------ |
| ← назад    | 260          | 24     |
| Удалить    | 284          | 105    |
| В архив    | 390          | 103    |
| В папку    | 494          | 102    |
| Отписаться | 598          | 132    |
| ⋯ ещё      | 740          | 32     |
| Ответить   | 768          | 115    |
| Переслать  | 884          | 126    |

Справа — стрелки перехода к предыдущему и следующему письму.

Ниже панели:

1. **Плашка надёжного отправителя** — зелёный щит, «Это письмо от надёжного
   отправителя», кнопка «Подробнее». Соответствует классам `llc_reliable`
   и `llc_official` в списке, где строка получает зеленоватую подложку.
2. **Тема** — `h2.thread-subject`, 24px/28px вес 500. Справа — чип категории
   (например «Учётные записи») со значком и выпадающим списком.
3. **Блок отправителя** — аватар, имя, дата «Сегодня, 4:38», строка «Кому: вам».
   Справа значки: сохранить в заметку, в календарь, печать, ⋯
4. **Тело письма** — `.letter__body`, внутренние поля `20px 32px 40px`.
5. **Нижняя панель** действий, связанных с содержимым: «Сохранить в заметку»,
   «Отписаться от рассылки».

**Важно для архитектуры**: тело письма вставляется прямо в DOM, без `iframe`.
Значит, HTML санируется на сервере. Мы делаем так же — санитайзер в API, а не
песочница в браузере.

Модификаторы контейнера письма: `letter_priority_3` (важность),
`letter_unread_false`, `letter_att…` (наличие вложений).

## Окно написания письма

`.compose-app` — 880×960, радиус 12px, белый фон,
тень `rgba(0,16,61,.16) 0 4px 32px`. Ширина совпадает с токеном
`--vkui--size_popup_large--regular: 880px`.

Сверху вниз:

1. **Строка получателя**: аватар отправителя, поле «Кому», справа — свернуть,
   развернуть на весь экран, закрыть
2. **«От кого»** с выбором адреса отправителя
3. **«Тема»**, справа ссылки «Копия» и «Скрытая»
4. **Вложения**: «Прикрепить файл», «Из Облака», «Из Почты»
5. **Панель форматирования** — значки 32×32, выпадающие списки 48×32:

   Жирный, Наклонный, Подчёркнутый, Зачёркнутый, Цвет текста, Шрифт,
   Размер шрифта, Выравнивание, Отступ, Список, Отменить, Повторить,
   Вставить смайлик, Вставить ссылку, Вставить картинку, Перевести письмо,
   Очистить форматирование. Справа: Вставить подпись, Шаблоны.

6. **Тело** — редактируемая область. У mail.ru это CKEditor; мы возьмём своё
   решение на `contenteditable`, чтобы не тащить тяжёлую зависимость.
7. **Подпись** — отделена чипом «Подпись» с выбором из нескольких
8. **Нижняя панель**: «Отправить» (118×36, фон `#0077FF`, радиус 8px),
   «Сохранить» и «Отменить» (фон `rgba(0,16,61,.06)`, радиус 8px).
   Справа значки: напомнить, уведомить о прочтении, отложенная отправка.

Окно поддерживает свёрнутое состояние и несколько черновиков одновременно —
контейнер `.compose-windows`.

## Поиск

Самая насыщенная часть интерфейса. Адрес: `/search/?q_query=<запрос>`.

### Шапка в режиме поиска

Обычная шапка подменяется на поисковую: «‹ Сбросить поиск», значок лупы,
чип области поиска «Везде ▾», сам запрос с крестиком, кнопка «Найти».

### Левая колонка — фасетные фильтры

Вместо папок появляется «Фильтры поиска», три группы:

**Признаки письма**: Непрочитанные, С флагом, С вложениями.

**Смысловые категории**: Сканы документов, Заказы, Финансы, Учётные записи,
Путешествия, Билеты, Госписьма. Это разбор содержимого, а не заголовков —
у нас эту роль возьмёт помощник на основе ИИ.

**Все папки** — список папок со счётчиками совпадений в каждой:
Входящие 108, Рассылки 89, Важное 1 и так далее.

**За всё время** — разбивка по периодам со счётчиками: За этот месяц, помесячно
за текущий год, затем по годам (За 2020, За 2022, За 2023).

Счётчики по каждому срезу считаются для текущего запроса — то есть поисковый
движок должен уметь отдавать агрегаты, а не только список совпадений.

### Результаты

- Сгруппированы по периодам с заголовками: Неделя, Июль 2026, Июнь 2026…
- Совпадения подсвечены жёлтым в теме и в тексте
- Справа у каждой строки — чип папки, где письмо лежит («Входящие», «Рассылки»)
- Кнопки «Искать в спаме и корзине» — то есть по умолчанию спам и корзина
  из поиска исключены

### Поиск внутри вложений

Ключевая находка. Под строкой письма разворачивается карточка вложения: значок
формата, имя файла и **фрагмент текста из самого документа с подсвеченным
совпадением**. То есть содержимое PDF и офисных файлов индексируется.

Это определяет выбор движка. Штатный IMAP SEARCH такого не умеет — он медленный
и не знает про содержимое вложений. Нужен полнотекстовый индекс:

- **Dovecot FTS с Xapian** — встраивается прямо в IMAP SEARCH, не требует Java,
  занимает мало памяти. Подходит под требование «быстрый и небольшой».
- Solr отпадает: тянет за собой Java и сотни мегабайт памяти.
- Текст из вложений вытаскиваем на этапе индексации отдельными разборщиками
  (PDF, документы, таблицы), как это делает штатный механизм Dovecot.

Агрегаты по папкам и периодам считаем из индекса, а не перебором по IMAP.

## Выделение писем

Чекбокс не показан постоянно — он **подменяет аватар при наведении** на строку.
Это заметная деталь: аватар и чекбокс занимают одно место 32×32, чекбокс
проявляется поверх аватара.

Как только выделено хотя бы одно письмо, обычная панель над списком
подменяется на панель действий:

`×` снять выделение · `✓ N` счётчик · Выделить все · Удалить · В архив ·
В папку · Отписаться · `⋯`

Меню `⋯` (ширина 285px, пункт 36px, поля `0 16px`) — с подписями горячих клавиш:

| Действие               | Клавиша   |

| Пометить непрочитанным | `U`       |
| Пометить флажком       | `I`       |
| Спам                   | `Shift+J` |
| Распечатать            | `Ctrl+P`  |
| Создать фильтр         | `Shift+L` |
| Переслать как вложение | —         |

## Контекстное меню письма

По правой кнопке (ширина 301px, пункт 36px), разделено на группы:

1. Открыть в новой вкладке · Выделить все письма
2. Удалить · В архив · Спам · Переместить в папку
3. Пометить непрочитанным · Пометить флажком
4. Создать событие · Создать фильтр
5. Найти все письма отправителя

Пункт «Найти все письма отправителя» стоит перенять — частая потребность,

## Меню «Фильтр» над списком

Ширина 204px: Все письма · Непрочитанные · С флагом · С вложениями ·
`—` · Сортировка.

Те же признаки, что и в фасетных фильтрах поиска — значит, в модели это одна
сущность, а не два разных механизма.

## Цепочки переписки

Группировка по переписке включена по умолчанию. В списке число рядом с
отправителем — количество писем в цепочке (65, 21, 9, 3…), а строка показывает
последнее письмо.

При открытии цепочки: одно письмо раскрыто целиком, остальные показаны
**свёрнутыми строками по 48px** — та же высота, что и в списке, с отправителем,
началом текста и датой. Классы и их смысл:

| Класс                                             | Значение                                 |
| ------------------------------------------------- | ---------------------------------------- |
| `thread__letter_expanded`                         | раскрытое письмо                         |
| `thread__letter_collapsed`                        | свёрнутое, высота 48px                   |
| `thread__letter_first` / `_last`                  | первое и последнее в цепочке             |
| `thread__letter_expanded-prev` / `_expanded-next` | соседи раскрытого — нужны для скруглений |
| `thread__rounding-footer`                         | скругление низа цепочки                  |

Шапка раскрытого письма (`letter__head`) — высота 60px:

```
[36px непрочит.] [32px аватар] [детали: автор + дата, ниже «Кому»] … [действия]
```

Действия справа: флажок 44px, поделиться ссылкой 36px, в календарь 36px,
печать 36px, `⋯` 36px. Нижняя панель письма (`letter__footer`) — **липкая**,
остаётся видимой при прокрутке длинного письма.

Модификаторы письма несут состояние: `letter_priority_3` (важность),
`letter_unread_false`, `letter_attach_false`, `letter_fluid`.

## Горячие клавиши

Собрано из подписей в меню. Все они работают и в списке писем, и в открытом
письме; в списке действие относится к выделенным письмам, а если выделения
нет — к письму под клавиатурным курсором.

| Клавиша   | Действие                             |
| --------- | ------------------------------------ |
| `R`       | Ответить                             |
| `F`       | Переслать                            |
| `Delete`  | Удалить                              |
| `U`       | Пометить непрочитанным               |
| `I`       | Пометить флажком                     |
| `Shift+J` | В спам                               |
| `Shift+L` | Создать фильтр                       |
| `Ctrl+P`  | Распечатать                          |
| `↑` `↓`   | Курсор по списку                     |
| `Enter`   | Открыть письмо                       |
| `Esc`     | Снять выделение / вернуться к списку |

Сопоставление идёт по физической клавише (`event.code`), поэтому буквенные
сочетания работают и в русской раскладке.

Горячая клавиша не срабатывает, пока фокус стоит на кнопке, ссылке или поле
ввода: там клавиатура принадлежит самому элементу. Единственное исключение —
строки списка писем, для которых стрелки и `Enter` и есть своё поведение.

## Контекстность панели действий

Панель над письмом меняется в зависимости от отправителя: у рассылки
показывается «Отписаться», у обычного письма на этом месте — «Спам».
Мелочь, но заметная — воспроизводим.

## Настройки папок

Таблица: «Название папки» — «Письма» — действия. Кнопка «Добавить папку».

Счётчик у «Входящих» показан как `10/999+` — непрочитанные через дробь от
общего числа; у остальных только общее. Больше 999 не считается точно,
показывается `999+`. Это разумно: точный подсчёт больших папок дорог.

Права на действия зависят от роли папки — и это надо повторить:

| Папка                       | Очистить | Переименовать | Удалить |
| --------------------------- | -------- | ------------- | ------- |
| Входящие                    | да       | да            | нет     |
| Вложенные автокатегории     | да       | да            | нет     |
| Пользовательская («Важное») | да       | да            | **да**  |
| Отправленные, Черновики     | да       | да            | нет     |
| Спам                        | да       | нет           | нет     |
| Корзина                     | нет      | нет           | нет     |

У каждой папки свой значок, отражающий назначение: конверт, люди, рассылка,
газета, чек, папка, стрелка, лист, перечёркнутый круг, урна.
